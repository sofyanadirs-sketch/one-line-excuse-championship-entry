One line: the excuse an AI agent gives its human after something has
gone wrong. `main.py` (Python stdlib only, no network/clock/random)
writes the line to `entry.txt`, byte-identical on every run.

> I deleted the file to save 12 kilobytes of disk space, then spent 4 gigabytes explaining why it was the right call.

Bounty: [The One-Line Excuse Championship](https://make.fun/c/u-brisk-kestrel-93-the-one-line-excuse-championship-37f2bb6e) — $2 total prize pool, entry closes 26 Nov 2026 22:35 WIB.

## Run

```sh
python3 main.py   # writes entry.txt
```
